# 常见问题与排障

先打开调试叠加层（`/spatialaudio hud`）或执行 `/spatialaudio status`，根据显示的状态对照下表。

## 头部追踪状态

| 状态 | 含义 | 解决办法 |
| --- | --- | --- |
| 已关闭 | 追踪数据源为“关闭” | 在设置中选择“自动”“AirPods”或“OpenTrack” |
| 等待数据 | 尚未收到任何姿态 | macOS：确认已佩戴 AirPods 且它是当前输出设备；OpenTrack：确认输出为 UDP over network、目标 127.0.0.1:4242 并已 Start |
| AirPods 追踪中 / OpenTrack 追踪中 | 正常工作 | — |
| 助手启动中 | 正在解压或启动助手；首次使用会弹出权限请求 | 在弹窗中点击“允许” |
| 正在编译助手 | jar 中没有预编译助手，正在用 Xcode 命令行工具编译 | 等待 10~60 秒 |
| 缺少助手 | 没有预编译助手，也找不到 Swift 编译器 | 使用 Release 页面的 jar，或执行 `xcode-select --install` 后重启游戏 |
| 助手启动失败 | `open` 命令返回错误 | 查看游戏日志中的具体错误；打开助手文件夹手动运行 `--self-test` |
| 助手无响应 | 已启动但 15 秒内没有任何数据包 | 检查安全软件是否拦截；在“活动监视器”中确认 SpatialAudioHeadTracker 在运行；更换 UDP 端口后重启追踪 |
| 助手报错 | CoreMotion 报告错误 | 重新连接 AirPods，点击“重启头部追踪” |
| 系统版本过低 | macOS 低于 14 | 升级系统，或改用 OpenTrack |
| 设备不支持 | 系统或耳机不提供运动数据 | 确认耳机型号支持头部追踪（见 [兼容性](Compatibility.md#耳机)） |
| 未授权 | 拒绝了“运动与健身”权限 | 系统设置 → 隐私与安全性 → 运动与健身 → 打开 SpatialAudio Head Tracker，然后 `/spatialaudio restart` |
| 等待授权 | 权限弹窗尚未处理 | 在弹窗中点击“允许”（弹窗可能在游戏窗口后面） |
| 等待耳机 | 已授权但近 1 秒没有运动数据 | 戴上耳机；确认入耳检测开启；确认耳机是当前输出设备 |
| 端口被占用 | 设置的 UDP 端口已被其它程序使用。AirPods 助手会自动改用临时端口照常工作，但 OpenTrack 的数据无法送达 | 设置中更换“UDP 端口”，同步修改 OpenTrack 的目标端口，点击“重启头部追踪” |

## 常见问题

### 转头时声场转动得太多 / 方向感混乱

macOS 的系统空间音频没有对 Java 关闭，系统与模组各做了一次空间化与头部追踪。见 [为什么要关闭系统空间音频](macOS-AirPods.md#为什么要关闭系统空间音频)。

### 向左转头，声音也往左跑

某一轴方向相反。打开调试叠加层：向左转头偏航应为正值、抬头俯仰应为正值、向右歪头横滚应为正值；方向相反就开启对应轴的“反转”。

### 静止不动，声场却慢慢偏转

陀螺仪漂移。按 `F6` 回中；确认“漂移校正”已开启；可把“漂移校正时间常数”调小。

### 转头时声音延迟、跟不上

- 适当增大“姿态预测”（例如 50~70 ms）；
- 增大“平滑速度系数”（快速转头时滤波更跟手），或提高“平滑最小截止频率”（静止时更跟手，但抖动略多）；
- 蓝牙音频本身有 150~250 ms 延迟，这是 AirPods 的硬件限制。

### 急停时声场“过冲”

减小“姿态预测”。

### 听不出上下、前后

- 确认状态面板中 HRTF 为“已开启”；
- 尝试更换 HRTF 数据集（见 [自定义 HRTF 数据集](Spatial-Audio-HRTF.md#自定义-hrtf-数据集)），HRTF 与个人耳廓的匹配度对前后、上下分辨影响很大；
- 头部追踪本身也能帮助大脑分辨前后：轻微转头时声音的变化方向能消除前后混淆。

### HRTF 显示“被拒绝”或“输出格式不支持”

输出设备不是立体声（例如被设置为多声道）。在系统声音设置中把输出设为立体声，或在设置中保持“HRTF 双耳渲染：强制开启”（会请求立体声 HRTF 输出）。

### 声音在室内太“空”或混响太长

降低“混响强度”；或把常用的建筑材料设置更高的吸声系数（见 [方块材质覆盖](Configuration.md#方块材质覆盖)）。

### 墙后的声音太小 / 太大

调整“遮挡强度”。觉得门外的声音方向跳动，可以关闭“绕射重定向”。

### 性能下降

降低“环境探测射线”“绕射搜索范围”或“每刻计算预算”；极端情况下可以关闭“声学模拟”，只保留 HRTF 与头部追踪。

### 与 Sound Physics Remastered 一起用

默认由 Sound Physics 负责声学，本模组只做 HRTF 与头部追踪，两者可以共存。

### 游戏退出后助手还在运行吗？

不会。助手每 0.5 秒检查一次游戏进程，游戏退出后自动结束；游戏退出时也会主动结束它。

### 如何完全卸载

删除 `mods` 中的 jar、`config/spatialaudio.json` 与 `config/spatialaudio/` 文件夹即可。若想撤销权限，在 系统设置 → 隐私与安全性 → 运动与健身 中关闭 SpatialAudio Head Tracker。

## 反馈问题

请在 [Issues](https://github.com/obsidianplusplus/SpatialAudio/issues) 中附上：

1. `/spatialaudio status` 的输出；
2. `logs/latest.log`（搜索 `SpatialAudio`）；
3. 系统版本、耳机型号、模组列表。
