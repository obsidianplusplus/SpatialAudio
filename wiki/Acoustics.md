# 声学模拟

HRTF 解决了“声音从哪个方向来”，声学模拟解决“声音在什么样的空间里传播”。本模组参考建筑声学与游戏音频中的常用方法，在 Minecraft 的方块世界里实时模拟混响、遮挡、绕射、回声、空气吸收与介质效果。

所有读取世界的计算都在客户端主线程完成（这是唯一能安全访问世界数据的线程），结果写入不可变对象，再由声音线程平滑地应用到 OpenAL。每个游戏刻的计算时间受“每刻计算预算”限制（默认 1.5 毫秒），超出部分顺延到下一刻，不会造成卡顿。

## 方块材质

Minecraft 26.x 已经没有“方块材质”属性，但每个方块都有决定脚步声的 `SoundType`，它与真实材料高度相关，因此作为主要依据：

| 材质组 | 典型方块 | 每格遮挡 | 吸声系数 | 听感 |
| --- | --- | --- | --- | --- |
| 石质 | 石头、深板岩、砖、凝灰岩、玄武岩、下界砖 | 1.0 | 0.03 | 明亮、混响长 |
| 金属 | 铁块、铜、铁砧、下界合金、灯笼、锁链 | 1.1 | 0.02 | 极明亮 |
| 木质 | 木板、原木、书架、梯子、竹 | 0.8 | 0.12 | 温暖 |
| 玻璃 | 玻璃、染色玻璃 | 0.5 | 0.04 | 透声但反射强 |
| 软质 | 羊毛、地毯、苔藓、蜂蜜块、黏液块 | 1.5 | 0.75 | 沉闷、几乎无混响 |
| 海绵 | 海绵、湿海绵 | 1.4 | 0.90 | 极度吸声 |
| 颗粒 | 沙、灵魂沙、灵魂土 | 1.0 | 0.25 | 偏暗 |
| 土石 | 沙砾、泥土、草方块、泥巴 | 1.0 | 0.20 | 偏暗 |
| 雪 | 雪块、细雪 | 0.9 | 0.60 | 吸声明显 |
| 植物 | 树叶、藤蔓、作物、花瓣 | 0.25 | 0.45 | 透声 |
| 晶体 | 紫水晶 | 0.9 | 0.02 | 清脆 |
| 幽匿 | 幽匿块、感测体、尖啸体 | 1.0 | 0.55 | 吸收振动 |
| 流体 | 水 / 岩浆 | 0.35 / 0.8 | 0.03 / 0.1 | 水面强反射 |

吸声系数参考建筑声学常用数据（500 Hz~1 kHz 附近）。没有碰撞箱的方块（花、草、火把、蜘蛛网）视为空气；门、栅栏、台阶、玻璃板等非完整方块会用碰撞箱做精确的射线相交测试，打开的门不再挡声音。可在配置中按方块 ID 覆盖遮挡与吸声系数，见 [配置参考](Configuration.md#方块材质覆盖)。

## 环境混响

### 环境探测

听者周围按斐波那契螺旋均匀发射射线（默认 64 条，分 8 刻完成一轮，每轮旋转一个黄金角错开采样），用 **Amanatides & Woo 体素遍历算法** 沿射线逐格前进，找到第一个反射面。统计：

| 量 | 含义 |
| --- | --- |
| 封闭度 | 探测距离内命中方块的射线比例 |
| 平均自由程 l | 命中射线的平均距离，代表声音两次反射之间走过的平均路程 |
| 表面吸声 ᾱ | 命中表面的平均吸声系数 |
| 有效吸声 | 把逃逸到探测距离外的射线按吸声系数 1 计入（声能离开了这个空间） |
| 天空开阔度 | 向上射线逃逸的比例 |

### Eyring 混响时间

Eyring 公式适用于吸声不均匀、偏“干”的空间，比 Sabine 公式更准确：

```text
RT60 = 0.161 · V / (−S · ln(1 − ᾱ))
```

对任意形状的空间有平均自由程 `l = 4V/S`，代入得：

```text
RT60 = 0.04025 · l / (−ln(1 − ᾱ_有效))
```

因此：空间越大混响越长；墙面越硬（石头、金属）混响越长；开口越多（逃逸射线多）混响越短。理想石室的理论值可达十几秒，模组对 RT60 做软压缩 `10·(1 − e^(−RT60/10))`，使长混响平滑地趋近 10 秒，避免声音浑浊。

### 映射到 EAX 混响参数

| EAX 参数 | 来源 |
| --- | --- |
| 衰减时间 | 软压缩后的 RT60 |
| 整体增益 | 随封闭度增大，随天空开阔度减小 |
| 早期反射增益 / 延迟 | 封闭度 × (1 − 表面吸声)；延迟 ≈ 0.6·l / 声速 |
| 后期混响增益 / 延迟 | 封闭度^1.5 × √(1 − 表面吸声)；延迟 ≈ 0.9·l / 声速 |
| 高频衰减比 | 表面越软，高频衰减越快；长混响额外变暗 |
| 回声密度 | 空间越大越稀疏 |
| 扩散度 | 随封闭度增大 |
| 调制深度 | 长混响时加入轻微调制，避免金属感 |

参数每 100 毫秒以 0.6 秒的时间常数平滑过渡，从洞外走进洞内时混响自然地“长”出来。

## 遮挡

听者到声源的线段经过的每个方块，按“材质遮挡系数 × 穿过的实际厚度”累加遮挡量 O（声源与听者所在的格子不计入，例如音符盒、唱片机本身）：

```text
直达声高频增益 = exp(−O × 1.0)
直达声整体增益 = exp(−O × 0.1)
```

墙越厚越闷，但低频比高频更容易穿透，与真实墙体的透射损失特性一致。通过 EFX 低通滤波器（`AL_LOWPASS_GAIN` / `AL_LOWPASS_GAINHF`）实现。遮挡强度可在设置中调整。

## 绕射与声音重定向

现实中，隔壁房间的声音主要从门口、窗户“绕”过来，而不是穿透墙壁。模组在直达路径被遮挡时搜索一条空气通路：

1. **加权 A\* 寻路**：从声源所在格出发，在可通行的格子（空气、树叶、水、打开的门、栅栏缝隙等）中做 6 邻域搜索，启发函数为到听者的直线距离（权重 1.5），优先朝听者方向扩展，遇到墙体时沿墙面寻找开口。搜索范围限制在以声源与听者为焦点的椭球内，并限制最多访问的格子数（默认 3000）。
2. **拉绳平滑**：A\* 得到的格子路径是折来折去的，从听者出发尽量直接“看到”路径上更远的点，只在被遮挡处保留拐点，得到真实的折线路程。彼此相距很近的拐点（穿过同一个门洞产生的）合并计为一次绕射。
3. **增益**：

   ```text
   路径增益 = exp(−额外路程 / 24) × 0.92^拐点数 × 透射系数
   路径高频 = 路径增益 × 0.85^拐点数
   ```

   最终增益取直达路径与绕射路径中较大的一个。
4. **重定向**：听者沿通路看到的第一个拐点方向就是“声音听起来来自的方向”。模组按两条路径的高频能量比，把声源的感知位置向这个方向旋转（最多 85%），同时保持真实距离不变，因此距离衰减不受影响。

效果：站在房间里，门外走廊的僵尸声会从门口传进来；绕到墙的另一侧，声音方向随之移动。

## 远距离回声

水平方向的射线会延伸到更远的“回声探测距离”（默认 96 格）。当 18 格以外有足够多的反射面、头顶开阔且不处于封闭空间时，判定为山谷、峡谷等地形：

```text
往返时间 t = 2d / 343
```

使用 EFX 回声效果（第一拍最长 0.207 秒，其余时间放到第二拍），反馈量随回声面比例增大。声源到回声效果槽的发送量由类别的混响发送比例决定。

## 空气吸收

空气会吸收高频，距离越远越明显。模组为世界中带距离衰减的声源设置 `AL_AIR_ABSORPTION_FACTOR`（OpenAL Soft 按每米约 0.994 的高频增益衰减），下雨时倍率 1.6，雷雨 1.8。

## 介质滤波

| 听者所在介质 | 整体增益 | 高频增益 | 混响 |
| --- | --- | --- | --- |
| 水 | 0.80 | 0.15 | EFX 水下预设 |
| 岩浆 | 0.60 | 0.06 | 低沉短促 |
| 细雪 | 0.85 | 0.45 | 保持环境混响 |

音乐与界面音效不受介质影响。

## 多普勒效应

默认关闭。开启后，模组根据位置变化估计听者与声源的速度（瞬移、跨维度时自动清零），写入 `AL_VELOCITY`，并设置 `alDopplerFactor`。鞘翅高速飞过声源时会听到音高变化。

## 性能

| 项目 | 开销控制 |
| --- | --- |
| 环境探测 | 每刻约 8 条射线，单刻方块缓存 |
| 声源遮挡 | 近处每 3 刻、远处每 6 刻刷新；超出衰减距离的声源直接跳过 |
| 绕射寻路 | 只对被遮挡的声源执行，访问格子数有上限 |
| 新声音 | 播放瞬间同步计算；单刻超过 24 个新声音时只算直达路径，超过 96 个推迟到下一刻 |
| 时间预算 | 每刻超过预算即停止，剩余工作顺延 |
| OpenAL 写入 | 只写入有变化的参数；批量提交（`alDeferUpdatesSOFT`） |

如需更低开销，可减少“环境探测射线”“绕射搜索范围”或降低“每刻计算预算”。
